# todoresolution

Microsoft To Do の「今日の予定」タスクに、緊急度・重要度・解像度を付けて優先順位を可視化するためのデスクトップGUIツール。

## できること

UI 上部はメニューバー(「タスク」「パーパス」「管理」)で操作する。各項目名の `(X)` はキーボードショートカット(Windowsのニーモニック)で、例えば Alt→T→D で選択中のタスクを Done にできる。

「タスク(T)」メニュー
- 「Add(A)」で、タスク名を直接入力して新規タスクを1件追加する(緊急度・重要度・解像度は既定値 5.0 から開始)。
- 「Done(D)」で、テーブルまたはバブルチャートで選択中のタスクを完了(DONE)状態にする。DONEになったタスクは、テーブル上でタスク名に取り消し線が引かれ、行の背景がグレーになり、常にテーブルの一番下(DONEでないタスクより下)に移動する。総合評価・重要度・緊急度・解像度の値は変更されず保持される。バブルチャートからは消える。
- 「Undone(U)」で、選択中のDONEタスクをもとの状態(通常表示・バブルチャートに再表示)に戻す。DONEタスクはバブルチャートには表示されないため、選択はテーブル上で行う。
- 「Delete(L)」で、選択中のタスクを削除する(確認ダイアログあり)。何も選択していない場合は案内メッセージを表示する。
- 「パーパス(P)」→ サブメニューに「なし」と、作成済みのパーパス名が並ぶ。選択中のタスクに、そのパーパスを割り当てる(「なし」で解除)。DONE状態の場合は行の見た目はDONE表示が優先される。

「パーパス(P)」メニュー(目的の管理。目標=解像度の低いタスクとは別に、タスクが仕える上位の目的を最大4つまで登録できる)
- 「Create(C)」で、パーパス名を入力し、続けて色(赤・橙・黄・緑・青・藍・紫の虹の7色、または「なし」=無地/白)を選ぶ。既に4つ登録済みの場合や同名が既にある場合はエラーを表示する。
- 「Delete(L)」→ サブメニューに登録済みのパーパス名が並ぶ(未登録なら無効化)。選択すると確認の上で削除し、それを割り当てられていたタスクは自動的に「なし」に戻る。
- 登録したパーパスは、右側のタスクテーブルの真上に表形式(パーパス名・その色を行背景色で表示)で一覧される。
- タスク側では、パーパスを割り当てると右側のタスクテーブルの行背景色がそのパーパスの色になる(バブルチャートのバブルの色は変化しない)。

「管理(M)」メニュー
- 「Extract(E)」で、Outlook デスクトップアプリの受信トレイから、件名「Microsoft To Do - 今日の予定」のダイジェストメールを読み込み、トップレベルのタスクのみを抽出する。
- 「Extract from File(F)」で、ファイル選択ダイアログから指定したテキストファイル(既定 `.md`)の内容からタスクを抽出する(Outlook が使えない環境向け)。
  - 想定する入力は、Microsoft To Do を OneNote に印刷し、その印刷イメージを「全ページからテキストをコピー」して保存したテキスト。書式は Extract(Outlookメール)とは異なる。
  - 「今日の予定」「MicrosoftToDoで印刷」等の見出し行、「タスク・日今日」「日次タスク・日今日0」等の種別行、日付のみの行(例: `2026年9月13日`)、ページ番号行(例: `1/2`)、装飾用の区切り行(`〇` の連続)を自動的に無視し、それ以外の行をタスク名として取り込む。
  - いずれの抽出方法でも、既存のタスクがあれば新しく読み込んだタスクと突き合わせ、両方に存在するタスクは既存の緊急度・重要度・解像度・DONE状態を維持したまま、新規タスクの追加/消えたタスクの削除のみ行う(値は上書きされない)。
- 「Reset(R)」で、全タスクの重要度・緊急度を (5, 5) に一括リセットする(解像度・DONE状態・パーパスは変更しない)。
- 「Save(S)」で、任意のタイミングでタスクごとの緊急度・重要度・解像度・DONE状態・パーパス、およびパーパス一覧を SQLite データベース(`todoresolution.db`)に保存する。
- 「Close(C)」で、Save と同様に保存してからウィンドウを閉じる。次回起動時は自動的に読み込まれ、前回終了時の状態が復元される。

抽出したタスクはバブルチャート上に表示され、ドラッグ操作で緊急度・重要度・解像度を設定できる(DONEになったタスクを除く)。左右の表示幅は図(バブルチャート):表 = 7:3。
  - 横軸: 重要度 / 縦軸: 緊急度(共に軸は逆進で、原点(左下)が(10, 10)、右下端が(0, 10)、左上端が(10, 0))
  - バブルの中心付近をドラッグ: 位置(重要度・緊急度)を移動
  - バブルの縁付近をドラッグ: サイズ(解像度)を変更

総合評価 = 重要度² × (緊急度 + 0.5 × (10 - 解像度)) を自動計算し、右側のテーブルに表示する。DONEでないタスクは総合評価の降順、DONEのタスクはその下にまとめて(同じく総合評価の降順で)表示する。

To Do 側への書き戻しは行わない。優先順位の確認結果は、ユーザーが手動で Microsoft To Do に反映する運用を想定している。

## セットアップ

前提: Windows + Outlook デスクトップアプリ(会社メールにサインイン済み)、Python 3.9 以降。

```
pip install -r requirements.txt
```

## 実行方法

```
python main.py
```

メニューの「管理(M)」→「Extract(E)」を選ぶと、Outlook 受信トレイから対象メールを検索して読み込みます(複数件ある場合は最新のものを使用)。

## 注意事項

- 初回実行時、Outlook のセキュリティ機能により「プログラムがメール情報にアクセスしようとしています」という確認ダイアログが表示されることがあります。その場合は許可してください(組織のセキュリティポリシーによりダイアログの挙動は異なります)。
- 件名「Microsoft To Do - 今日の予定」のメールが受信トレイに存在しない場合は、エラーメッセージが表示されます。
- メール本文のうち、字下げされたサブタスクや Notes 等は取り込み対象外です。インデントのないトップレベルの `⬜` 項目のみを取り込みます。
- 「Extract from File」が対象とする OneNote 印刷イメージのコピーテキストには、用途不明の装飾行(`〇` の連続)が含まれることがある。現状は既知のパターンとして無視しているが、OneNote 側のレイアウトが変わるとノイズ行の形式が変化し、取り込み漏れ・誤取り込みが起きる可能性がある。
- タスクの同一性はタスク名(文字列)で判定しています。同名タスクが複数存在する場合は区別できません。
- `todoresolution.db` はプロジェクト直下に作成されます。削除すると保存済みの値はリセットされます。

## EXE化(配布用実行ファイルの作成)

PyInstaller を使って単体の `.exe` を作成できる。

```
pip install pyinstaller
pyinstaller --noconfirm --windowed --onefile --name todoresolution --icon=icon.ico --add-data "icon.ico;." main.py
```

- `--windowed`: コンソールウィンドウを表示しない(GUIアプリ用)
- `--onefile`: 単一の `.exe` にまとめる
- `--icon=icon.ico`: エクスプローラー/タスクバー上の`.exe`自体のアイコンを設定する
- `--add-data "icon.ico;."`: `icon.ico` を実行時に読み込めるようexe内に同梱する。ウィンドウ左上のタイトルバーアイコン(Tkinterの既定の羽根アイコン)は `--icon` だけでは変わらず、`src/app.py` 側で `self.iconbitmap(...)` により起動時に読み込んで設定しているため、この同梱が必要
- 生成物は `dist/todoresolution.exe`。`todoresolution.db` は `.exe` と同じフォルダに作成される(実行のたびに作られる一時フォルダではなく、`.exe` の場所を基準にしている)。
- Outlook 連携(`Extract`)を使う場合、実行するPCに Outlook デスクトップアプリ(クラシック版、`OUTLOOK.EXE`)が必要。新しい Outlook(`olk.exe`)は COM 自動化に対応していないため動作しない。「Extract from File」はこの制約を受けない。
- `build/` と `*.spec` は生成物なので配布時は `dist/todoresolution.exe` のみで良い。再ビルド時は `build/`・`dist/`・`*.spec` を削除してから実行すると安全。
